# AutoParts

Primeiro projeto que faço sozinho, independente da faculdade, com o objetivo de estudar e praticar Python e desenvolvimento backend.

### O que estudei até agora
- Python e Flask
- MySQL e modelagem de banco de dados
- Consultas SQL e relacionamentos entre tabelas
- Login e autenticação
- Integração entre frontend e backend
- Git e GitHub

### Desafios
Um dos principais desafios foi entender melhor a regra de negócio do projeto. Inicialmente, eu relacionava as peças diretamente aos veículos, mas percebi que fazia mais sentido relacioná-las aos motores, já que um mesmo motor pode estar presente em diferentes veículos.

Com isso, precisei mudar a estrutura do banco de dados para representar melhor o funcionamento do sistema.

Projeto ainda em desenvolvimento. Vou atualizando esse README conforme o projeto evoluir e eu aprender coisas novas.
